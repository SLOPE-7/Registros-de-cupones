KAL CUPÓN ORGANIZADOR — BÚSQUEDA Y GUARDADO DE ESCUDOS

QUÉ INCLUYE
- Busca equipos y ligas desde API-Football; limpia puntos, guiones y símbolos antes de consultar.
- Permite elegir candidatos y muestra una vista previa del escudo; si el catálogo no encuentra un equipo, permite guardar manualmente una URL de API-Football.
- La sección “Logos” reúne equipos de cupones guardados y en revisión; permite buscar, elegir o pegar una URL, guardar y actualizar cada escudo. Desde cada partido de Mercados también se abre la edición de los escudos de ambos equipos.
- Muestra el escudo directamente desde API-Football y también intenta guardarlo en IndexedDB del navegador para reutilizarlo.
- Guarda también los resultados de búsqueda. El botón no repite las consultas al proveedor si ya hay resultados guardados.
- Limita a tres búsquedas nuevas por minuto para proteger el cupo.
- Si el proveedor no tiene una imagen, muestra las iniciales del equipo.
- La clave API se mantiene solo en Netlify.

PASOS
1) Crea una cuenta en API-Football y activa el plan Free. Copia tu API key del panel. El plan Free publica actualmente 100 solicitudes diarias y un límite de 10 por minuto.
2) En Netlify agrega la variable de entorno API_FOOTBALL_KEY con tu clave real. Marca “Contiene valores secretos”; puedes dejar “Todos los ámbitos”. No envíes la clave por chat.
3) Descomprime este ZIP y publica el contenido completo con Netlify CLI o un repositorio Git conectado. Deben ir juntas las carpetas site y netlify, y los archivos netlify.toml y LEEME.txt.
4) Después de publicar, Netlify debe mostrar las funciones: escudos, logo, partido, jugadores y catalogo.
5) En la página publicada, pega un cupón, pulsa “Leer y revisar”, pulsa “Buscar logos”, elige los resultados y pulsa “Aplicar selecciones”.
6) Si aparece un aviso de cuota, consulta Usage en el panel API-Football. Si se agotó el límite por minuto, espera un minuto; si el cupo diario está en cero, espera a que se renueve.

NETLIFY CLI
- Abre PowerShell dentro de la carpeta KAL_Cupon_Netlify, donde está netlify.toml.
- Ejecuta:
  npx netlify-cli login
  npx netlify-cli link
  npx netlify-cli deploy --prod
- Selecciona tu sitio actual cuando aparezca la pregunta de enlace.

NOTAS
- Sin iniciar sesión, los logos se guardan localmente. Con la cuenta Supabase configurada, el catálogo de escudos también se sincroniza entre dispositivos.
- La opción “Borrar cupones y movimientos” conserva el catálogo local de escudos y logos, incluidas las imágenes guardadas en IndexedDB.
- Si una competición no aparece en el catálogo, puedes añadir su URL manualmente.
- Los datos de cupones de file:// y del dominio Netlify están separados; exporta/importa un respaldo para trasladarlos.


ACTUALIZACIÓN: MEJORAS DE CUPONES Y SINCRONIZACIÓN
- Logos: la lista separa equipos pendientes de equipos con escudo guardado. Cada equipo puede buscar/actualizar el escudo y quitarse de la lista. Los logos guardados se conservan al borrar cupones.
- Calendario: muestra escudos, nombres y competencia; al pulsar un partido abre su cupón.
- Inicio: muestra cupones ganados, perdidos, anulados/cash out, importes y una gráfica de balance neto.
- Cupones guardados: tarjetas ordenadas con equipos, escudos, estado y montos; incluye registrar cash out.
- Si todos los mercados de un cupón ya están liquidados y alguno fue anulado, la app solicita el retorno final real que pagó la casa.
- Casas rápidas: Hondubet, Doradobet, Betpro y Catraplay. Se agregan con saldo inicial cero.

CUENTAS Y NUBE (CONFIGURACIÓN ÚNICA)
La cuenta en la nube usa Supabase. La app no recibe ni almacena la contraseña de la cuenta; la autenticación se procesa mediante Supabase. La dirección del proyecto y su clave pública se guardan en el navegador. Para sincronizar entre dispositivos, crea un proyecto Supabase, copia la URL y la clave pública (anon/publishable) en Configuración y ejecuta este SQL desde el SQL Editor:

create table if not exists public.kal_user_data (
  user_id uuid primary key references auth.users(id) on delete cascade,
  payload jsonb not null default '{}'::jsonb,
  updated_at timestamptz not null default now()
);
alter table public.kal_user_data enable row level security;
create policy "read own KAL data" on public.kal_user_data for select to authenticated using ((select auth.uid()) = user_id);
create policy "insert own KAL data" on public.kal_user_data for insert to authenticated with check ((select auth.uid()) = user_id);
create policy "update own KAL data" on public.kal_user_data for update to authenticated using ((select auth.uid()) = user_id) with check ((select auth.uid()) = user_id);

Después, abre Configuración en KAL, pega URL y clave pública, crea la cuenta con tu correo y contraseña e inicia sesión. Si solicita verificar el correo, confirma el mensaje y vuelve a iniciar sesión. En los demás dispositivos abre el mismo sitio, pega la misma URL y clave pública e inicia sesión con la misma cuenta. La primera sincronización combina registros locales y remotos; los cambios guardados se envían automáticamente. Los escudos también se sincronizan.

IMPORTANTE
- Nunca compartas la clave service_role; usa solo anon o publishable.
- Descarga respaldos periódicos. Sin configurar Supabase, el resto de KAL sigue funcionando localmente.


MEJORA DE CALENDARIO Y FICHA DE PARTIDO
- Calendario muestra fecha y hora en cada encuentro y conserva el agrupado por día; los partidos con fecha/hora disponible se ordenan cronológicamente.
- Mercados se ordena por fecha y hora y muestra esos datos junto a cada partido.
- Al pulsar un partido en Calendario, Mercados, el cupón guardado o la vista previa se abre una ficha común con fondo de estadio, escudos, competición, fecha/hora y mercados para marcar.


NUEVAS MEJORAS
- En Logos, “Buscar con URL” pide solo el ID de API-Football y forma automáticamente la dirección oficial para escudos de equipos y ligas. Al guardarlo, se reutiliza en los partidos y dispositivos sincronizados.
- Al abrir la ficha de un partido, las pestañas Mercados y Cupones muestran los datos locales. Análisis, Estadísticas y Eventos consultan API-Football al abrirse; la cobertura y la disponibilidad pueden variar por liga y fecha. Las cuotas muestran probabilidad implícita; los porcentajes de predicción se identifican como datos de API-Football. No se inventan posiciones, lesiones, estadísticas ni nivel de confianza cuando no hay datos.
- Para conectar la ficha con API-Football, ambos escudos deben llevar un ID numérico del proveedor y el partido debe tener fecha.
- En mercados de goleador/remates y otros mercados de jugador, “Buscar foto del jugador” consulta por nombre y equipo; las fotos dependen de los datos de API-Football.

- Corrección móvil: al abrir la ficha, la página de fondo queda fija y solo se desplaza el contenido del partido.
- Corrección de análisis: la temporada se obtiene de la fecha del encuentro y una tabla no disponible ya no bloquea las predicciones restantes.

- Los partidos y mercados ahora se agrupan ignorando acentos y sufijos comunes de clubes (FC, SK, CF, etc.); se mantienen los nombres originales guardados en los cupones.
- La ficha muestra tarjetas de mercado más compactas, especialmente en teléfonos.

ACTUALIZACIÓN: DETECCIÓN Y FICHA DEL PARTIDO
- Los partidos repetidos se consolidan comparando los nombres sin tildes y sin sufijos habituales como FC, SK, CF, FK, SC, AFC y similares. Se conservan los nombres que venían en el cupón.
- La ficha del partido ahora es más compacta. En móvil, la cabecera y las pestañas permanecen visibles y se desplaza solo la información del partido.
- Al consultar el análisis, la búsqueda contempla el día anterior y posterior para cubrir cambios de fecha por zona horaria. La tabla de posiciones ya no impide mostrar las demás respuestas si API-Football no tiene la temporada.
- El importador detecta país y competencia cuando el texto del cupón los incluye. Si aplicas un resultado de liga desde “Buscar logos”, también actualiza automáticamente el nombre de la competencia, país y bandera del partido.
- En Logos se puede buscar un país por código ISO de dos letras (por ejemplo, ES o GB) y una liga por su ID. API-Football no asigna un ID numérico a los países; el código ISO es el identificador admitido por su consulta de países.
- Las búsquedas de nombres limpian tildes y signos no admitidos por el proveedor. Si API-Football no tiene ese partido, jugador o estadística, la app lo indica sin fabricar datos.
- “Buscar foto del jugador” muestra errores y reestablece el botón al terminar; acepta nombres con tildes y sufijos de equipo.

CORRECCIONES DE FICHA DE PARTIDO
- El modal móvil usa ahora un área de desplazamiento propia con altura limitada; la cabecera y las pestañas permanecen visibles mientras se desplaza la información.
- Análisis muestra forma y estadísticas de temporada cuando API-Football no publica una predicción, y consulta H2H por separado. La tabla ausente se explica en pantalla.
- Estadísticas, eventos y alineaciones pueden no existir antes del inicio del encuentro o en ligas sin esa cobertura. Usa “Actualizar datos” dentro de la ficha para volver a consultar.
- La búsqueda de fotos del jugador tiene límite de espera, consulta el plantel actual si falla el índice de temporada y avisa si la imagen no está disponible.
- Las respuestas de partidos se pueden actualizar manualmente; la consulta de partidos encontrados se reutiliza temporalmente para reducir solicitudes repetidas.


FOTOS DE JUGADORES
- El buscador acepta el ID del equipo enviado por la pantalla, busca primero en la temporada indicada y recurre al plantel actual si no encuentra al jugador.
- Al encontrarlo, guarda la foto en el catálogo de Logos junto al nombre del jugador, club y país; la foto aparece también en la tarjeta del mercado. El catálogo usa el mismo respaldo/sincronización de logos que la app.


AJUSTE DEL CATÁLOGO DE JUGADORES
- La sección Logos reúne todos los mercados detectados de remates, goleador, anotador y jugador en cupones guardados y en el borrador actual. Desde la tarjeta se puede buscar la foto.
- La búsqueda usa primero Football Players Profiles de API-Football por apellido; ya no depende de que coincidan el ID del club y la temporada. Guarda el nombre del jugador, su nacionalidad, el club asociado y la URL de foto.
- La foto se muestra directamente desde la URL pública de API-Football tanto en Logos como en la tarjeta del mercado.


VERSIÓN 4 — CORRECCIONES Y NUEVO DISEÑO
Errores corregidos
- Jugadores: los mercados de equipo (por ejemplo "Total de remates - Como" o "Marcador correcto 2-1") ya no aparecen como jugadores.
- Jugadores: el código del club (COM, NAP, RMA…) ya no se mezcla con el nombre; se usa para identificar el club correcto. Los nombres guardados antes con el código se limpian solos al abrir la app.
- Mercados: la vista "Pendiente" muestra solo mercados que siguen vivos. Si un cupón se perdió, se cobró (cash out) o se anuló, sus mercados desaparecen de Pendiente. "Todos" muestra el historial completo.
- Agenda: los partidos de cupones perdidos ya no aparecen como pendientes.
- Eliminar un cupón ahora también quita su apuesta automática del balance de la casa ("Deshacer" la recupera).
- Nube (Supabase): los cupones, casas y movimientos eliminados ya no reaparecen al sincronizar, y se conserva la versión más reciente de cada cupón (los resultados marcados no se pierden). Los catálogos de logos se combinan en lugar de reemplazarse.
- El respaldo descargado ahora incluye escudos, logos y fotos de jugadores.

Diseño
- Pantallas más compactas y ordenadas, pensadas primero para el teléfono.
- Encabezado con el nombre de la sección y botón "+ Nuevo cupón" que lleva directo al lector.
- Menú inferior con 5 accesos (Inicio, Agenda, Mercados, Cupones y Más). En "Más" están Logos, Casas y balances, Estadísticas y Ajustes.
- Inicio: indicadores en una fila; primero pegas el cupón, luego revisas la vista previa y al final completas los datos.
- Logos: cada lista (equipos sin escudo, con escudo, jugadores, ligas, eliminados…) es una sección que se expande y se contrae con su contador. La app recuerda cuáles dejaste abiertas y, al buscar, abre las que tienen resultados.


VERSIÓN 5 — MODO OSCURO Y FICHA DEL PARTIDO
- Corrección: Estadísticas, Eventos y Análisis mostraban "The Season field is required". La función "partido" ahora envía la temporada que exige API-Football (y prueba la otra temporada si el partido no aparece).
- Nueva paleta azul noche, dorado y verde. Modo oscuro predeterminado; en Ajustes → Apariencia puedes elegir Oscuro, Claro o Automático (según el teléfono). El botón ☀/☾ del encabezado cambia rápido entre oscuro y claro.
- Inicio es ahora un panel: indicadores, botón "Registrar nuevo cupón", partidos de hoy (por jugar, en juego, liquidados) y resumen de apuestas.
- "Nuevo cupón" es una pantalla propia con el lector. La vista previa muestra cada partido resumido (equipos, fecha, mercados y cuotas); los campos se editan solo al tocar "✎ Editar".
- Agenda con atajos Hoy, Mañana, Semana y Todos, y tarjetas de partido con escudos, hora, competición, "EN VIVO" y número de mercados.
- Ficha del partido: encabezado más compacto; mercados en tarjetas pequeñas con cuota y barra de probabilidad implícita; la opción marcada se rellena de color; marcar un resultado ya no te devuelve arriba; los mercados ya marcados se guardan en la sección plegable "Ya marcados".
- Mercados: el historial de resultados es una sección plegable con contador.
- Balances: tarjeta con el banco actual (suma de todas las casas) y el resultado neto.


VERSIÓN 5.1
- Mis cupones: por defecto solo se ven los pendientes. Los ganados, perdidos y nulos / cash out quedan archivados en sus pestañas (con contador); "Todos" muestra el historial completo.
- Regla del cupón perdido: si un mercado se marca como perdido, todo su cupón queda perdido. Sus partidos y mercados desaparecen de Agenda, Mercados (Pendiente), Inicio y de los pendientes de la ficha del partido (allí pasan a "Ya marcados y cerrados" con la etiqueta "cupón perdido"). Si el mismo partido también está en otro cupón que sigue vivo, se sigue mostrando por ese cupón.
- API-Football: el aviso "Free plans do not have access to this season" ahora se explica en español. El plan gratis solo permite temporadas 2022–2024, así que Análisis, Estadísticas y Eventos de partidos actuales requieren un plan de pago. Los escudos y las fotos de jugadores sí funcionan con el plan gratis.


VERSIÓN 6 — APP INSTALABLE Y ESTADÍSTICAS DE RENDIMIENTO
App instalable
- KAL se puede instalar en el teléfono con su propio ícono. En iPhone: abre el sitio en Safari → Compartir → "Agregar a inicio". En Android: menú → "Instalar aplicación" (o el botón "Instalar" que aparece en Inicio).
- Instalada, abre a pantalla completa, funciona sin conexión (los datos de API-Football sí necesitan internet) y el teléfono conserva mejor los datos.
- La app pide al navegador que no borre sus datos.
- Recordatorio en Inicio si pasa más de una semana sin descargar un respaldo (no aparece si usas la sincronización en la nube).
- Archivos nuevos: site/manifest.webmanifest, site/sw.js y la carpeta site/icons. netlify.toml incluye cabeceras para que las actualizaciones lleguen enseguida.

Estadísticas → "Tu rendimiento"
- Periodo: 30 días, 90 días, este año o todo.
- ROI y resultado neto, % de cupones ganados, % de mercados acertados y rachas.
- Conclusión automática: tu tipo de mercado más fiable y el que más te falla (con al menos 3 resultados).
- Gráfica de resultado neto por mes (azul = ganancia, naranja = pérdida; colores elegidos para que se distingan también con daltonismo).
- Acierto por tipo de mercado, por rango de cuota y por competición, con la rentabilidad "suelta" (si cada mercado se hubiera apostado por separado a 1 unidad).
- Resultado y ROI por casa de apuestas.
- Cada mercado cuenta una sola vez aunque esté en varios cupones; los nulos no cuentan en el % de acierto.


VERSIÓN 7 — AVISOS DE PARTIDOS, PRESUPUESTO Y RACHAS
Avisos de partidos (notificaciones del teléfono)
- En Más → Ajustes → "Avisos de partidos" pulsa "Activar avisos en este teléfono" y acepta el permiso.
- En iPhone solo funciona con KAL instalada en la pantalla de inicio (iOS 16.4 o superior).
- Elige cuántos minutos antes avisar (5, 10, 15, 30 o 60) y si quieres otro aviso cuando el partido empiece.
- Llegan aunque KAL esté cerrada. Se avisa de los partidos con mercados pendientes de cupones vivos en los próximos 7 días; al perderse un cupón, sus partidos dejan de avisarse.
- "Enviar prueba" manda una notificación al momento para comprobar que funciona.
- Con la app abierta también aparece un aviso arriba de la pantalla (se puede desactivar).
- Funcionamiento: la función "avisos" guarda los próximos partidos de cada teléfono y la función programada "avisos-envio" revisa cada 5 minutos qué avisos tocan. Usa Netlify Blobs (incluido en Netlify) y crea sola sus claves; no hay que configurar nada.
- Archivos nuevos: package.json (Netlify instala @netlify/blobs y web-push al publicar), netlify/lib/avisos-comun.mjs, netlify/functions/avisos.mjs y netlify/functions/avisos-envio.mjs.

Presupuesto mensual y rachas
- En Inicio, "Define tu presupuesto mensual": barra con lo apostado este mes, aviso al 80 % y al superar el 100 %. El presupuesto se sincroniza con la nube.
- Aviso en Inicio cuando llevas 3 o más cupones perdidos seguidos.
- Las notificaciones muestran la hora del partido, la competición y los mercados pendientes (hasta 3, y "y N más"). En iPhone siempre aparece el ícono de KAL: iOS no permite mostrar otras imágenes en notificaciones de apps web.


VERSIÓN 8 — CÓDIGO ORDENADO, BUSCADOR Y GUARDADO RÁPIDO
Buscador global
- Botón 🔎 en el encabezado. Escribe un equipo, un jugador o el nombre de un cupón (al menos 2 letras).
- Equipos: partidos y % de mercados acertados. Jugadores: club, mercados y su estado. Cupones: estado e importe.
- Incluye los cupones archivados. Toca un partido para abrir su ficha o un cupón para ir a él.

Guardar más rápido
- La casa de apuestas se elige sola: por su nombre en el texto, por el formato del texto (comparado con tus cupones guardados de cada casa) o, si no hay pistas, la última que usaste. Debajo se explica el motivo.
- Botones con tus importes habituales debajo de "Importe apostado".
- Se recuerda si marcas "Registrar la apuesta en el balance".
- Barra fija "Guardar cupón" con el resumen (selecciones, importe, cuota y casa) mientras revisas la vista previa.

Organización del código (site/)
- index.html: solo la estructura de las pantallas.
- css/: estilos por capas, en orden (01-base … 10-buscador-guardado). Cada capa ajusta a las anteriores.
- js/: lógica por temas, en orden de carga:
    01-nucleo · 02-lector-cupones · 03-reglas-cupones · 04-escudos · 05-nuevo-cupon-resultados
    06-agenda-mercados · 07-logos-jugadores · 08-cupones-casas-estadisticas · 09-nube · 10-ficha-partido
    11-navegacion-eventos · 12-tema · 13-app-instalable · 14-avisos-presupuesto · 15-guardado-rapido
    16-buscador · 99-arranque (inicia la app; siempre el último)
  Los archivos comparten sus funciones y variables. Para añadir uno nuevo, agrégalo en index.html antes de 99-arranque.js y en la lista SHELL de sw.js.
- sw.js: modo sin conexión. Si agregas o renombras archivos, súbele la versión (CACHE = 'kal-vN').

Pruebas automáticas (pruebas/)
- node pruebas/ejecutar.mjs  (desde la carpeta KAL_Cupon_Netlify; necesita Playwright: npm i -D playwright && npx playwright install chromium)
- Revisan el lector, la detección de jugadores, la regla del cupón perdido, Mercados, Agenda, Mis cupones, eliminar y deshacer, guardado rápido, buscador, avisos, presupuesto, rachas, modo sin conexión y las funciones de Netlify (con API simulada).
