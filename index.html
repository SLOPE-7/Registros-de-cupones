Configuración y memoria

✓Memoria local
Los cupones y el borrador se guardan en el almacenamiento de este navegador.

La memoria local funciona aunque cierres la página, pero no sincroniza automáticamente entre dispositivos ni navegadores. Si borras los datos del navegador, podrías perder los registros; exporta un respaldo periódicamente.

La lectura de texto funciona sin conexión. La lectura directa de imágenes requiere OCR, que esta versión independiente no incluye; puedes usar la función de texto de tu teléfono para copiar el texto de una captura y pegarlo aquí.
